# PyTorch Fundamentals — Tensors, Devices, and the Model Lifecycle (LFD2000)

- **Exam domain:** PyTorch Fundamentals (38%)
- **Estimated length:** ~3.7 hours
- **Course level:** Beginner

## Description

Learn PyTorch from the ground up: create and manipulate tensors, understand device placement, and build your first complete model workflow — from training through saving and prediction — by solving a real classification problem.

## Subtopics Covered

- **Core Concepts** — The fundamental architecture and mechanics of neural networks within the PyTorch ecosystem
- **Tensors** — Properties, types, creation, and manipulation of tensors as PyTorch's primary data structure
- **Training, Testing, and Using Models** — The end-to-end lifecycle of a machine learning model
- **Device Basics (CPU, CUDA, MPS)** — Hardware environments for running PyTorch workloads effectively
